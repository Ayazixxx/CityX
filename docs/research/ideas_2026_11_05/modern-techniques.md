# Modern game-dev techniques (my web searches, 2026-11-05; X itself needs the owner's sign-in in the browser pane)

## Crowds and characters
- Vertex animation textures (VAT) / GPU skinning: skinned meshes cannot be GPU-instanced because skinning runs on the CPU; bake animation into textures and skin on the GPU. Unity's Animation Instancing post (2018): 50 bones x 30 keys = 6000 px per clip, 1024^2 holds ~174 clips. https://blog.unity.com/engine-platform/animation-instancing-for-skinnedmeshrenderer ; free Unity VAT baker (1000+ Animators vs VAT demo) https://80.lv/articles/free-tool-for-baking-vertex-animation-textures-directly-in-unity ; trade-off: no Mecanim blending (hand-written state). Fit for CityX: far crowd players/civilians drawn as VAT impostor bodies, near ones real.
- Animation LOD (update rate by distance): full rate near, throttled far; one manager updates all in one loop and spreads phases so frames don't spike. https://kybernetik.com.au/animancer/docs/samples/fine-control/update-rate ; https://mocaponline.com/blogs/mocap-news/animation-lod-performance-guide
- Motion matching: JLPM22/MotionMatching (MIT, Unity 6+, inertialization blending, foot locking, ~584 stars) https://github.com/JLPM22/MotionMatching ; MxM community fork https://motion-matching-for-unity.readthedocs.io ; Kinema (new, Unity 6000.3+, Burst search) https://awesome.ecosyste.ms/projects/github.com%2Fnekuzaky%2Fkinema . Needs a mocap library; CityX bakes Godot/Blender clips, so a later step.
- Active ragdolls (Euphoria-style): an invisible animated "ghost" rig drives a physics rig with PD/PID muscles; hits drop muscle tension, then a get-up; 5-6 active characters on PC. https://80.lv/articles/make-your-characters-feel-alive-with-this-self-balancing-active-ragdoll-system ; https://gamedeveloper.com/design/8-tips-for-animating-active-ragdolls ; EA/Frostbite driven ragdolls. CityX already has grapple ragdoll + get-up clips: hit reactions could blend into physics.

## Rendering (Unity 6 / URP 17)
- GPU Resident Drawer: BatchRendererGroup instancing of ordinary GameObjects, best for big scenes with many shared meshes (a city!); needs Forward+ and compute; slightly more GPU work; does NOT handle skinned meshes. https://docs.unity3d.com/6000.3/Documentation/Manual/urp/gpu-resident-drawer.html
- GPU occlusion culling (works with the Resident Drawer; bounding spheres; can cost more if little occlusion). https://docs.unity3d.com/6000.4/Documentation/Manual/urp/gpu-culling.html
- STP upscaler: Unity's own spatial-temporal upscaler; needs TAA; works with render scale (not dynamic resolution). Render at ~70% and upscale. https://docs.unity3d.com/Manual/urp/stp/stp-upscaler.html
- Impostors + HLOD for far buildings: octahedral impostors replace far meshes with camera-facing baked cards; Unity doc table: 140k-tri mesh x800 instances 62.5 ms -> 4.01 ms. https://docs.unity3d.com/Packages/com.unity.pixyz.unity-sdk@4.0/manual/features/impostors.html ; MegaCity HLOD + streaming impostors https://discussions.unity.com/t/hlod-streaming-octahedral-impostors-using-megacity-subscenes/742223

## Networking
- Lag compensation (collider rollback): the server puts hitboxes back to the tick the shooter saw, then raycasts; FishNet has it (Pro for raycasts), needs fixed interpolation; projectiles over time don't need Pro. https://fish-networking.gitbook.io/docs/guides/features/lag-compensation ; general https://kindatechnical.com/game-development/lag-compensation-prediction-interpolation-and-rollback.html

## AI
- Hybrid enemy AI: a squad blackboard for coordination, utility AI or GOAP for choices, behaviour trees/state machines for execution; utility AI is the indie favourite (XCOM-like scoring), GOAP for multi-step plans (F.E.A.R.). https://gamedeveloper.com/programming/indie-ai-programming-from-behaviour-trees-to-utility-ai ; https://kindatechnical.com/game-development/decision-making-utility-ai-and-goap.html

## Procedural generation
- Graph-based wave function collapse: neighbourhood -> building interiors -> furniture, recursive; global coherence is plain WFC's weakness. https://logan169.github.io/2025/01/18/Graph-Based-WFC.html ; Unity WFC city with ScriptableObject tile rules https://github.com/Basinity/CitySimulator
